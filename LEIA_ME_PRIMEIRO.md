# DeltaTV — Admin (pacote cumulativo V4)

Arquivos relativos à raiz do projeto `admin/`. Incluem telas de configuração de
planos/pacotes e Apps da plataforma que pertenciam aos patches V4 anteriores.
Nenhuma alteração adicional no Admin foi necessária para o erro do modal Meus Apps.
Não muda import, alias, Vite ou cópias locais de /shared.

Esta entrega é patch cumulativo, não cópia integral do projeto. Compare `git diff`
antes de aplicar para não sobrescrever alterações posteriores.

Testar `npm run build` na raiz do Admin após preparar o ambiente e sincronizar
UI pelo mecanismo do repositório canônico (quando existente).
